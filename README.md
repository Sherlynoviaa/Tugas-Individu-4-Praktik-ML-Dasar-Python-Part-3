## Hasil Praktik Dasar Python

Berikut adalah spesifikasi lingkungan kerja dan poin materi yang telah dipraktikkan:

* **Editor:** Visual Studio Code (VS Code) / Jupyter Notebook
* **Bahasa Pemrograman:** Python 3
* **Topik Utama:** Struktur Kontrol (If, Elif, Else), Perulangan (For, While), dan Pembuatan Fungsi (Function & Lambda).

### Langkah-Langkah Praktik:

1.  **Setup File:** Membuat file python dengan ekstensi `.ipynb` (Jupyter Notebook) di dalam workspace.
2.  **Implementasi Percabangan:** Mempraktikkan logika pengambilan keputusan bersyarat menggunakan `if`, `elif`, dan `else` (contoh: program kriteria lamaran kerja dan konversi *grade* nilai).
3.  **Eksperimen Perulangan (Loops):** Menggunakan `for` loop untuk melakukan iterasi pada berbagai tipe koleksi data (List, Tuple, Set, Dictionary) serta membuat otomasi pola string (pola bintang).
4.  **Implementasi Perulangan Dinamis:** Menggunakan `while` loop untuk mengeksekusi blok instruksi secara terus-menerus selama kondisi bernilai *True*.
5.  **Pembuatan Fungsi:** Membungkus blok kode menjadi lebih modular menggunakan perintah `def` (fungsi kustom) dan fungsi anonim satu baris menggunakan `lambda`.

## Analisis & Kesimpulan

Berdasarkan praktikum yang telah dilakukan, dapat disimpulkan bahwa:

* **Efisiensi Looping:** Perulangan sangat menghemat waktu dan memori karena kita tidak perlu menulis ulang kode (repetisi) secara manual, terutama ketika harus mengeksekusi atau memanipulasi ratusan data sekaligus.
* **Modularitas Kode:** Penggunaan `Function` membuat struktur kode menjadi jauh lebih rapi, terstruktur, dan *reusable* (dapat dipanggil kembali kapan saja tanpa harus *copy-paste* rumusnya dari awal).
* **Kunci Computer Vision:** Logika percabangan (*if-else*) dan perulangan (*looping*) ini merupakan keterampilan fundamental yang krusial sebelum kita masuk ke tahap iterasi matriks citra dan manipulasi piksel pada library OpenCV nantinya.
